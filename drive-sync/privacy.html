JokerAI Brief Archive 隐私政策

更新日期：2026-10-27。此工具面向维护者的个人情报整理工作流，由用户自己的 Windows 电脑运行。

访问与用途

工具通过 Google OAuth 的 https://www.googleapis.com/auth/drive.file 权限创建、读取、核验及删除由本工具创建、或用户明确提供给本工具的 Drive 文件，并读取账户存储配额以避免持续占满空间。Google 授权用于用户请求的原文同步、检索与保留管理；本组件不请求读取所有 Drive 文件、Gmail 邮件或 Google 相册内容。

保存与删除

原文和索引保存在用户自己的 Windows 与 Google Drive。原文按最近发现日期保留 15 天；云端删除前先保存本地归档并核对内容哈希，两端到期正文按用户设置清理。标题、有限摘要、来源链接、内容哈希、处理记录和必要运行日志可保留供检索与去重，直到用户要求清除。故障或校验失败时暂停相关清理，可能暂时延长保存期限。

凭据与共享

OAuth 客户端配置及刷新令牌保存在用户 Windows 账户的受限私有目录，不写入公开网页、原文索引或邮件正文。同步文件默认保留用户自己的访问权限，不公开分享。此组件不出售 Google 用户数据，不用于广告，也不将这些数据用于训练通用模型。用户另行授权其他应用读取文件或邮件时，应以该应用的隐私政策和授权设置为准。

Google API 使用

本工具使用从 Google API 获得的信息时遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

用户控制与联系

用户可以停止 Windows 定时任务，在 Google 账号的第三方连接设置中撤销授权，并删除自己的本地或 Drive 文件。撤销授权后，本组件不能继续读取或上传文件。此公开说明页不接收用户原文、账户密码或令牌，没有广告或分析脚本。
